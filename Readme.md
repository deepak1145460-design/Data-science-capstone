# Data Science Capstone Project – SpaceX Falcon 9

This project contains a complete set of notebooks and files created to fulfill the required grading criteria for the Data Science Capstone Project.

## Files and Assignment Requirements

| File | Assignment Requirement |
|---|---|
| `01_data_collection_api.ipynb` | 1.5 – Data Collection using SpaceX API |
| `02_data_collection_webscraping.ipynb` | 1.6 – Data Collection using Web Scraping |
| `03_data_wrangling.ipynb` | 1.7 – Data Wrangling Methodology |
| `04_eda_visualization.ipynb` | 1.8, 1.11 – Exploratory Data Analysis with Data Visualization |
| `05_eda_sql.ipynb` | 1.9, 1.12 – Exploratory Data Analysis using SQL |
| `06_folium_launch_site_analysis.ipynb` | 1.10, 1.13 – Interactive Visual Analytics using Folium |
| `07_spacex_dash_app.py` | 1.10, 1.14 – Interactive Visual Analytics using Plotly Dash |
| `08_predictive_analysis_classification.ipynb` | 1.15 – Predictive Analysis |

The notebooks are designed to be executed in order from **01 to 08**, with the output of each stage being used in the subsequent analysis.

The project also includes data collection, data wrangling, exploratory data analysis, SQL analysis, interactive visualizations, and predictive analysis as required by the assignment.
